# Santa Cruz Endpoint Letter Outreach Archive

This folder preserves the Santa Cruz public-interest outreach work as an archive/reference package inside `apo` (Archive of Possibilities). It is not presented as a separate project repository.

## Contents

- `MASTER_RECIPIENT_LIST.csv` — current 115-record master recipient list, with category, address, and outreach status.
- `APPROVED_ENDPOINT_LETTER.md` — the approved endpoint/closure letter. This version is preserved as the approved text and should not be silently rewritten.
- `SEND_WORKFLOW.md` — operational rules for verification, batching, and status updates.

## Archive status

This material includes established campaign records, verified public contact information, unverified candidates, and ideas/proposals. Status labels are intentionally kept separate so that an unverified candidate is not treated as a verified recipient and a generated batch is not treated as sent.

## Important status rules

- `VERIFIED — UNSENT — ELIGIBLE FOR NEXT BATCH` is the only status eligible for a send-ready batch.
- `SENT — DO NOT RESEND` recipients are excluded from future batches.
- `DO NOT USE` recipients are excluded from future batches.
- Creating or displaying a batch does not mark it sent.
- A recipient is marked sent only after explicit confirmation that the message was actually sent.

## Scope note

The master list is the current 115-record campaign master reconstructed from the working files and explicit status corrections available at the time of archiving. Historical reconstructed records from earlier campaign work are not silently merged into this current master.

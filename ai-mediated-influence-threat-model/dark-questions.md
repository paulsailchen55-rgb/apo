# Dark Questions

These questions are intentionally difficult. They are not claims of fact.

1. What if a system can be manipulated without any single component appearing compromised?
2. What if the most effective attack is not changing an answer, but changing which questions a person asks?
3. What if an attacker can influence the timing of information more effectively than its content?
4. What if omission is more difficult to detect than alteration because investigators can only examine what was received?
5. What if a compromised source is trusted precisely because it has historically been reliable?
6. What if legitimate credentials are sufficient to make malicious activity appear authorized?
7. What if several individually harmless systems form a harmful chain when connected?
8. What if an AI system faithfully summarizes a manipulated information environment?
9. What if humans cannot independently reconstruct the information pathway that produced an important AI-mediated decision?
10. What minimum evidence would distinguish coordinated manipulation from correlated ordinary failures?
11. Can provenance be independently verified when the original source itself may be compromised?
12. What happens when the same corrupted information is independently copied into thousands of apparently separate sources?
13. Can a machine-detectable trigger exist inside content that appears meaningless to a human observer?
14. How can defenders test for dormant conditional behavior without accidentally activating it?
15. If a system's behavior changes only under a rare combination of state, input, timing, and context, how can that behavior be reproduced?
16. Could defensive monitoring itself become another attack surface?
17. How much independent observation is enough to establish that an AI-mediated pathway was intact?
18. At what point does ordinary information pollution become a security problem rather than merely a data-quality problem?
19. If an AI system becomes an intermediary for many institutions, does compromising the intermediary create systemic risk even without compromising each institution?
20. What evidence would falsify the strongest version of the "global chain reaction" hypothesis?

# Selective Librarian Interface

The Civic Two-Minute Ideas system already calls for current-source awareness, source provenance, document comparison, evidence handling, and human review.

The Selective Librarian provides a more general retrieval layer beneath those functions.

Instead of asking AI to summarize every available public document, the workflow can ask:

1. What is the user's actual question?
2. Which official sources are relevant?
3. Which sections contain the relevant evidence?
4. Why were those sections selected?
5. What remains uncertain or missing?
6. Can the user inspect the original source?

The two-minute output remains a human-reviewed communication product. The Selective Librarian is the navigation layer that helps reach the evidence used to prepare it.

Core boundary:

> Retrieval assists the human. Retrieval does not decide the human's position.

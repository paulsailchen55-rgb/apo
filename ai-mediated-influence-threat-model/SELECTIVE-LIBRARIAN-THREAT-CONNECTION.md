# Selective Librarian Threat Connection

A Selective Librarian creates a new security and governance question because any system that controls retrieval can also control attention.

The threat-model question is:

> What happens if a system selectively retrieves, suppresses, delays, misranks, or reframes information while presenting itself as a neutral librarian?

Relevant failure modes include:

- selective omission;
- biased ranking;
- personalization that becomes manipulation;
- poisoned metadata;
- false provenance;
- stale indexing;
- context removal;
- hidden retrieval criteria;
- denial of broader search;
- making unavailable material appear irrelevant.

Therefore a Selective Librarian should inherit the project's human-agency and anti-manipulation concerns.

Minimum safeguards:

- original records remain reachable;
- retrieval reasons are inspectable;
- search scope is user-controllable;
- provenance is preserved;
- missing versus irrelevant is distinguished;
- uncertainty is shown;
- broader search is available;
- the system does not silently infer sensitive traits to control access.

The central warning is simple:

> A librarian can become a gatekeeper if the reader cannot look beyond the librarian's selection.

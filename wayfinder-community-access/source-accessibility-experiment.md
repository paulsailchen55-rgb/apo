# WAYFINDER Source Accessibility Experiment

## Research question

How much useful local community information can current AI systems obtain directly, and how much remains dependent on humans who can access closed or social-media systems?

## Source classes

| Source | Machine access | Human access | Typical issue |
|---|---|---|---|
| Public webpage | usually possible | yes | page changes |
| Public PDF | usually possible | yes | stale documents |
| Public calendar / ICS | strong | yes | feed maintenance |
| Public database/API | strong | yes | access limits |
| Public social post | variable | yes | platform barriers |
| Private social group | often unavailable | member needed | access control |
| Phone confirmation | no | yes | labor |
| Word of mouth | no | yes | provenance/recency |

## Experiment

For each Santa Cruz listing, record:
- source type
- whether AI can access it
- whether current information can be extracted
- whether human intervention is required
- time required for verification
- how often the source changes

## Hypothesis

The bottleneck may be **information access**, not model intelligence.

This is a hypothesis to test, not a conclusion.

## Scaling implication

If most useful information is available through public structured sources, automation may scale substantially.

If a large share is trapped behind private social networks or human-only communication, a sustainable system may need explicit human participation rather than attempting to bypass access controls.

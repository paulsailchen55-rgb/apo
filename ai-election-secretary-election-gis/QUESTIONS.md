# QUESTIONS

## Product / system

- What is the smallest useful Election Secretary?
- Can it accept a webpage, PDF, transcript, image, or voice conversation as the initial input?
- Can it immediately produce a decision brief?
- Can it identify whether the input is a candidate, measure, law, institution, or general issue?
- Can it route different research tasks to different models/tools?
- Can routing be inspected?
- Can every important claim retain a source path?
- Can the system export Markdown, PDF, HTML, and structured graph data?
- Can it publish only after explicit human approval?

## Election GIS

- What geographic data model should represent city, county, state, federal, and special districts?
- How should overlapping jurisdictions be visualized?
- Can policy effects be mapped separately from voting eligibility?
- Can candidate relationships be layered over geographic boundaries?
- Can two candidates be compared without producing a ranking?
- Can "conflict" be visualized without turning it into a political judgment?

## Research

- What constitutes a primary source for each type of decision?
- How should campaign claims be distinguished from independently verified facts?
- How should negative claims be verified?
- How should evidence quality be represented?
- How should conflicting credible sources be displayed?
- How should the system handle a source that later changes or disappears?
- Can calculations be reproduced?

## Human agency

- How can the system avoid making the final political decision?
- How can it avoid inferring voting preferences?
- How can a user control which issues receive deeper research?
- Can users explicitly mark their own priorities without having the system infer them?
- Can the system preserve "I don't know yet" as a valid state?

## Global

- How should the system model single-party elections?
- How should it represent dominant-party systems?
- How should it represent referendums?
- How should it handle parliamentary systems?
- How should it handle proportional representation?
- How should it distinguish formal electoral rules from practical political conditions?
- How should it handle countries where access to information is restricted?
- How should it handle politically dangerous research environments?
- How should it represent elections that are internationally disputed?

## Ethics

- Could the same system become a persuasion engine?
- Could it be used for political microtargeting?
- Could a centralized AI provider become a civic information gatekeeper?
- What data should never be retained?
- Should political research histories expire automatically?
- What should "deletion" mean for cached research and derived graphs?

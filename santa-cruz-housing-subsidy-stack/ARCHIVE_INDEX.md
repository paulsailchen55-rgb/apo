## Known project direction

The project developed from a conventional “subsidy stack” inventory toward a broader systems audit:

**LAND → ZONING → DENSITY → DEVELOPMENT STANDARDS → FEES/EXACTIONS → CONSTRUCTION → FINANCING → SUBSIDIES → AFFORDABILITY → MARKET REVENUE → ADMINISTRATION → STABILITY → FEASIBILITY**

and then toward a transmission model:

**INTENDED HOUSING NEED → STATE REQUIREMENT → REGIONAL ALLOCATION / RHNA → LOCAL HOUSING ELEMENT → ZONING / SITE CAPACITY → PROJECT DESIGN → FINANCING + FEASIBILITY → PERMITTING / APPROVAL → CONSTRUCTION → OCCUPANCY / LEASE-UP → AFFORDABILITY → HOUSING STABILITY**

At each interface, audit:

**PROVENANCE → FRICTION → DISTORTION → LOSS → RECOVERY**

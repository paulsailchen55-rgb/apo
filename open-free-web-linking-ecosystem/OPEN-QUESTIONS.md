# Open Questions

## Service Questions

- Which free hosts allow commercial or personal use?
- Which services permit custom domains?
- Which services display mandatory advertisements?
- Which services support export, backups, and migration?
- Which services require accounts, credit cards, or recurring payment?
- What limits apply to bandwidth, storage, build minutes, AI credits, and inactivity?

## Linker Questions

- Can links use custom paths rather than opaque short codes?
- Can destinations be edited without changing the public link?
- Is the routing software open source?
- Can link data be exported?
- Does the system track visitors or collect personal information?
- Can it operate without a paid custom domain?
- What happens if the linker provider shuts down?

## User Protection Questions

- How can a nontechnical user understand where a link ultimately leads?
- How can users avoid phishing and deceptive redirects?
- How should broken or abandoned destinations be handled?
- What is the simplest backup and recovery procedure?
- How can the project remain useful to people with limited money, time, or internet access?

## Evidence Status

Service capabilities and pricing must be verified periodically. No provider should be treated as permanently free or permanently available without ongoing review.

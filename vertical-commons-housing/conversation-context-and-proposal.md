# Vertical Commons / Adaptable Housing — Conversation Context

## Status

Additional archive context for the existing Vertical Commons folder.

## Core proposal

A pillar-based, modular mixed-use foundation could support adaptable residential and community modules while preserving the ability to change uses over time.

Discussed elements include:
- accessible units
- senior housing
- affordable housing
- housing for people exiting homelessness
- mixed-use/community functions
- adaptable or replaceable modules
- green/park-like upper space
- microleasing
- truck-accessible delivery
- potential container/modular movement
- minimizing unnecessary tree removal

## Core design principle

Build the underlying infrastructure so that future residents retain options instead of locking the site into one irreversible configuration.

This is a proposal, not an established engineering or zoning solution.

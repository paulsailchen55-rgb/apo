# Public Record Access and Data Equity

## Status
Research direction / civic-infrastructure concept.

## Purpose
Study how residents can discover, access, verify, and understand public property and civic records without requiring proprietary real-estate subscriptions or specialized professional databases.

## Core distinction
Private aggregators can be useful research aids. The originating public record, when available, establishes the fact.

## Proposed access path
Start with the public source of record; identify the responsible agency; determine whether the record is free online, available by public request, available in person, subject to a fee, or only encountered through a private subscription database.

## Civic Flow Chart connection
Treat information access as a process node with an authority, source, clock, cost, access method, verification state, and fallback path.

## Limits
This does not claim that all public records are free, digitized, or legally required to be free. It is a research/design question about making access barriers visible and finding lawful free or low-cost pathways where they exist.

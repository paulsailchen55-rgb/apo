# Technical Approaches to Investigate

1. User-controlled source labels.
2. Audio classification models.
3. Device-level metadata and integration.
4. Acoustic feature analysis.
5. Human-in-the-loop confirmation.
6. Confidence scoring and an explicit unknown state.
7. Benchmark recordings containing live speech, speaker playback, and mixed conditions.

A first prototype should compare labeled test samples rather than assume that classification is reliable.

# Civic Flow Chart — Public Record Access Node

Information access should be visible as part of a civic process rather than treated as invisible background work.

Node fields:
- Need: what fact/document is required?
- Jurisdiction: who has authority?
- Custodian: who maintains the record?
- Source: where is the primary record?
- Access: web / request / in person / other.
- Cost: free / fee / subscription / unknown.
- Clock: expected response/processing time.
- Verification: when and how checked.
- Secondary clue: aggregator/report used for discovery.
- Conflict: disagreement between sources.
- Next path: clarification, alternate record, responsible office, or other lawful route.
- Change flag: has the source or procedure changed?

Rule: a commercial database can be a shortcut to discovery. It is not automatically the source of record.

Equity question: if the same public fact is substantially easier to obtain for a person who can afford a private database, record that access difference as a system condition. Do not assume the difference is unlawful or intentional; document actual access paths and costs.

This is a reusable component for property, planning, permits, public works, environmental review, and other civic processes.

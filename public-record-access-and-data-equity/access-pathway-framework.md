# Public Record Access Pathway Framework

For each requested fact, record:
1. Question — what fact/document is needed?
2. Jurisdiction — city, county, state, federal, or other.
3. Authority/custodian — who maintains or decides the record?
4. Source of record — the primary record or official database.
5. Access method — web, download, public request, mail, phone, in person, or other.
6. Cost — free, fee-based, subscription, unknown, or not located.
7. Clock — expected response or processing time.
8. Identity requirements — if any, without unnecessarily collecting personal information.
9. Verification — date checked and what was actually observed.
10. Secondary sources — aggregators/reports used only as discovery aids.
11. Conflicts — differences between sources.
12. Fallback — another lawful route if the primary source is difficult to access.
13. Change status — whether the source/procedure/result changed since the previous check.

Do not assume that a fee is improper or that a free source must exist. The access condition itself is part of the record.

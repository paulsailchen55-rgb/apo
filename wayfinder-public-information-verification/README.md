# Wayfinder: Public Information Verification

## Purpose

This folder preserves a practical research direction: helping people verify whether publicly advertised opportunities, services, events, and claims are available as described when they arrive in person.

The project is named provisionally. An earlier APO project called “Wayfinder” was not located by repository search during this update, so this folder should be treated as a related working record rather than a confirmed continuation of an existing folder.

The approach is observational and constructive. It does not assume that inaccurate information was intentional. It asks how public information can be made more current, accessible, transparent, and verifiable.

## Core questions

- What was advertised?
- Where was it advertised, and when was it last updated?
- What conditions or restrictions were stated?
- What did a person encounter on arrival?
- Could the information have changed shortly before arrival?
- Can independent observations be recorded without exposing unnecessary personal information?
- What correction or update process exists?

# Functional Packet Set — Archive Note

Four working packets were prepared from the broader idea log:

1. 1214 Soquel Avenue — Project Action Packet
   Immediate site-specific questions, community concerns, Plan B proposals, and adaptability/posterity questions.

2. Santa Cruz — Civic Proposals for Adaptable Development
   City-level actions: pilot adaptable infrastructure, preservation plus capacity, building documentation, material lifecycle, public demonstration, process mapping, accessible records, one-page decision guides, and research into distributed housing.

3. California — State-Level Proposals for Adaptable Development
   State-level research/proposal areas concerning housing law, adaptive reuse, modularity, financing, building standards, lifecycle documentation, and demonstration projects. It explicitly does not claim these are current law.

4. Development Research Lab — Experimental Ideas
   Test-first collection for pillar platforms, movable modules, road/rail transfer, productive vertical commons, microleasing, agricultural layers, building passports, and material recovery.

These packets are derivatives of the Master Idea Log, not replacements for the individual project folders.

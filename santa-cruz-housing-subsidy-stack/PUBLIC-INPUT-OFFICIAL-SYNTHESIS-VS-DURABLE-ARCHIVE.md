# Public Input: Official Synthesis vs. Durable Public Archive

**Status:** PROPOSED / RESEARCH DIRECTION

## Purpose

This document captures the proposed distinction between limiting the number or frequency of official feedback syntheses and preserving the underlying public input for future research, review, and analysis.

## Core Finding

**Synthesis limits should not become archival limits.**

An agency may decide that it only needs to synthesize public feedback a limited number of times—for example, one to three official reports. That administrative choice does not require the underlying submissions to disappear.

The central principle is:

> **Do not destroy the haystack simply because the system cannot yet reliably find the needle.**

A comment that appears unimportant during the current reporting cycle may later identify a recurring permitting problem, financing barrier, definition mismatch, overlooked population, project failure, or connection between systems that was not recognized at the time.

## Two-Layer Architecture

### Layer 1 — Official synthesis

```
PUBLIC INPUT
     ↓
STAFF / OFFICIAL REVIEW
     ↓
1–3 OFFICIAL SYNTHESIS REPORTS
     ↓
DECISION / IMPLEMENTATION
```

This layer can remain intentionally bounded. The agency can control reporting frequency, workload, document length, and the questions addressed by each formal report.

### Layer 2 — Open archival record

```
ANYONE
  ↓
SUBMIT COMMENT / OBSERVATION / IDEA / QUESTION
  ↓
PUBLIC ARCHIVE
  ↓
PERSISTENT RECORD
  ↓
SEARCH / HUMAN REVIEW / DATA ANALYSIS / AI
```

The archival layer does not assert that every comment is correct. It preserves the underlying record so that later researchers can examine it rather than relying entirely on whatever was selected for the official synthesis.

## Recommended Minimum Archive Record

A durable public-input system should preserve the original submission and enough metadata to make it discoverable and interpretable later.

| Field | Purpose |
|---|---|
| COMMENT_ID | Persistent identifier for the submission |
| DATE_RECEIVED | Establishes when the information entered the record |
| SUBJECT / PROJECT | Connects the submission to the relevant matter |
| JURISDICTION | Identifies the governmental or geographic context |
| SUBMITTER TYPE | Optional classification useful for analysis |
| ORIGINAL COMMENT | Preserves the underlying public input |
| ATTACHMENTS | Preserves supporting material where appropriate |
| PUBLICATION STATUS | Records whether and how the item was made public |
| OFFICIAL REPORT REFERENCES | Connects the comment to any later official synthesis |
| SUBSEQUENT ANALYSIS | Records later research or derived findings without replacing the original |

## Preserve the Original; Derive Analysis Separately

The archive should preserve the original submission rather than replacing it with an AI-generated summary.

A later analytical layer might identify that dozens of submissions describe a similar problem. That finding is a **derived observation**. It should remain distinguishable from the original comments that support it.

```
RAW ARCHIVE
     ↓
SEARCH
     ↓
HUMAN REVIEW
     ↓
AI / MACHINE ANALYSIS
     ↓
PATTERN DETECTION
     ↓
NEW RESEARCH QUESTION
```

The raw material remains available while calculations, classifications, pattern detection, and interpretations remain identifiable as derived work.

This fits the project's existing evidence discipline:

- **KNOWN**
- **CALCULATED**
- **TESTED**
- **PROPOSED**
- **SPECULATIVE**
- **UNKNOWN**

The original public submission belongs in the evidence/archive layer. An analytical statement derived from many submissions should remain identified as derived analysis rather than becoming indistinguishable from the underlying evidence.

## Design Principle for Future Systems

The archive should not be designed specifically for today's AI.

It should be designed as durable public information that future humans, search systems, statistical tools, AI systems, or other technologies can use.

The goal is **interoperability and discoverability over time**, not prediction about which technology will eventually find the most useful information.

The design should therefore preserve:

- original records;
- persistent identifiers;
- dates and reporting periods;
- subject/project relationships;
- provenance;
- relevant metadata;
- links to later official reports;
- links to later derived analyses where appropriate.

## Relationship to the Housing Transmission Audit

For the housing research project, this distinction fits the existing transmission-audit framework.

Public input can be another evidence layer around the housing pathway, while official reports remain one form of synthesis.

The archive can help preserve observations about interfaces where housing capacity, time, money, eligibility, definitions, responsibility, or information change.

A later researcher could compare those observations with:

- project records;
- permitting records;
- financing records;
- construction records;
- occupancy records;
- affordability monitoring;
- retention/preservation records;
- housing stability records.

The archive therefore supports the broader principle:

> **Map the system before proposing another system.**

## Important Governance Boundary

An open archive should not be understood as a guarantee that every submission must be accepted as factual, adopted as policy, or acted upon.

**Preservation and decision-making are separate functions.**

The archival design should also account for applicable public-records, privacy, accessibility, moderation, security, and records-retention requirements. Those requirements determine what can be published and for how long; this document does not attempt to resolve them.

## Recommended System Rule

> **Official synthesis answers: “What are we reporting now?”**
>
> **The archive preserves: “What did people actually say?”**

Keeping both layers allows an agency to limit the administrative burden of repeated formal reporting without making today's reporting structure the permanent boundary of tomorrow's knowledge.

## Bottom Line

A limited number of official reports and a broad public archive are not contradictory.

They serve different purposes.

**The official report is a synthesis layer.**

**The archive is the historical evidence layer.**

The research direction is therefore not “make the agency process every comment forever.” It is:

> **Allow the official process to remain bounded while preserving enough of the underlying public record that future humans and future tools can find information that today's process may overlook.**

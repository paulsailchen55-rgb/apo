# Santa Cruz County Housing — What We Can Do Now
## Two-Path Implementation Strategy: Conventional Housing Path + Weird/Experimental Path

**Project:** California Housing Transmission Audit  
**Geographic focus:** Santa Cruz County, California  
**Reference point:** 2026 state housing reforms and the County's adopted 6th Cycle Housing Element  
**Status:** Working strategy / research plan  
**Evidence discipline:** KNOWN / CALCULATED / TESTED / PROPOSED / SPECULATIVE / UNKNOWN

---

## 1. The Situation Has Changed

For years, local officials could reasonably point upward and say:

> California needs to do something.

California has now enacted another substantial round of housing legislation and administrative reform.

The Governor describes the 2026 housing package as modernizing affordable-housing finance, reducing duplicative reviews, changing impact-fee treatment, and reducing development costs. The state specifically describes a "One-Stop Shop" approach intended to streamline project delivery. These are state-reported objectives and estimates; this project should test the actual local effects rather than assume them. [KNOWN] 

The question for Santa Cruz County therefore changes.

We do not need to wait two or three years before doing anything.

Instead:

> **Use the new state policy environment as a reference condition now, prepare the County to use it, and establish measurements before implementation effects become difficult to separate from baseline conditions.**

---

# 2. Two Paths, Side by Side

We should deliberately pursue two research and implementation paths at the same time.

| Conventional County Path | Weird / Experimental Path |
|---|---|
| Work with the housing types people already build | Test a reconfigurable building/infrastructure platform |
| Use existing Housing Element programs | Use the same programs as interfaces for an unconventional project |
| Existing zoning and development pathways | Ask what happens when the building is designed for multiple future uses |
| Existing financing | Examine whether financing can recognize adaptability |
| Existing permitting | Measure every approval/review interface |
| Existing construction | Compare conventional construction against modular/offsite possibilities |
| Existing affordable housing programs | Test whether transaction reduction can improve long-term stability |
| Existing sites | Identify sites where a conventional project and an adaptable platform can both be modeled |
| Existing outcome metrics | Add transmission/stability metrics |
| Implement current law | Use the project to expose remaining friction in current law |

This is important:

> **The weird project should not sit outside the normal system. It should pass through the normal system so that we can observe exactly where it fits, where it doesn't fit, and why.**

# 3. Path A — The Normal County Housing Path

The County already has an adopted 6th Cycle Housing Element found by HCD to be in substantial compliance.

HCD specifically says the County must continue timely and effective implementation of its programs, including:

- H-1B — Accommodate RHNA
- H-1C — By-Right Overlay
- H-1D — State Density Bonus Law
- H-1E — Residential Flex Rezone
- H-1F — Multifamily Development Standards
- H-1H — Senate Bill 9 Implementation
- H-1J — Senate Bill 10 Implementation
- H-1M — Accessory Dwelling Units

[KNOWN]

The County path therefore does not begin with inventing another housing policy.

It begins with:

> **Map the new state reforms onto the County's existing implementation programs.**

## Step A2 — Establish the Baseline Before Measuring Improvement

Do this **now**, before the reforms have had time to produce their full effects.

Record, where available:

- permit-processing time;
- entitlement-processing time;
- plan-check cycles;
- number of review agencies;
- development fees;
- fee waivers/deferrals;
- financing sources;
- subsidy per unit;
- total development cost;
- construction duration;
- time from approval to construction;
- time from construction completion to occupancy;
- lease-up period;
- affordable-unit production;
- preservation;
- demolition;
- rehabilitation;
- occupancy continuity.

This creates the "before" condition.

Without a baseline, a later claim that the system became faster or cheaper cannot be cleanly attributed to the new state reforms.

# 5. County Path — The Three-Year Window

Do not think:

> "We have to wait three years."

Think:

> **"We have roughly a multi-year implementation experiment, and we should measure it from day one."**

### Year 0 — 2026

**Prepare and baseline**

- identify affected state laws;
- identify County implementation responsibilities;
- map existing Housing Element programs;
- collect baseline project data;
- identify candidate projects;
- identify data gaps;
- establish transmission metrics.

### Year 1

**Implement and observe**

- track regulations and County actions;
- record actual review sequences;
- document fees and financing;
- record project delays;
- identify unexpected new interfaces;
- compare planned versus actual capacity.

### Year 2

**Compare**

- compare pre-reform and post-reform project pathways;
- test whether processing actually changed;
- test whether cost changed;
- test whether feasibility changed;
- test whether more projects reached construction;
- test whether occupancy changed.

### Year 3

**Evaluate**

- measure stable housing output;
- determine whether friction disappeared or moved;
- identify remaining bottlenecks;
- recommend next-cycle reforms.

# 6. Path B — The Weird Project

The weird project is the **Modular Building Platform / Modular Parking-Garage Concept**.

It should be treated as a controlled research case, not as a predetermined solution.

Core concept:

```text
MODULAR STRUCTURAL FRAME
          ↓
BUILDING PLATFORM
          ↓
 ┌────────┼─────────┐
 ↓        ↓         ↓
PARKING  HOUSING  WORKSPACE
          ↓
    COMMUNITY USE
          ↓
 FUTURE ADAPTATION
```

The conventional model is:

```text
USE → BUILDING
```

The experimental model is:

```text
BUILDING PLATFORM → MANY POSSIBLE USES
```

The central question:

> **Can a long-lived adaptable building platform reduce the number of major transactions required when community needs change?**

This is a PROPOSED research hypothesis.

It is not assumed to be economically, legally, structurally, or politically superior.

# 9. The New State Reference Changes the Research Question

Previously we could ask:

> "What should California do?"

Now a better question is:

> **"California has changed the rules. How does Santa Cruz County convert those changes into actual local housing output?"**

And simultaneously:

> **"Where do the state reforms stop, and what local friction remains?"**

That distinction matters.

A state reform can:

- remove a barrier;
- reduce a cost;
- shorten a review;
- create a new funding pathway;
- require a local action;
- shift responsibility;
- or simply move friction to another interface.

# 11. What We Can Do Immediately

We do not need to wait for implementation outcomes.

## 1. Build the baseline

Find 3–5 real Santa Cruz County housing projects and reconstruct their pathway.

For each:

```text
SITE
→ ENTITLEMENT
→ FINANCING
→ PERMIT
→ CONSTRUCTION
→ OCCUPANCY
```

Measure time, cost, reviews, fees, and handoffs where records allow.

## 2. Build one hypothetical conventional project

Use a real or representative County site.

Determine:

- zoning;
- allowable density;
- development standards;
- parking;
- fees;
- likely financing;
- affordable-housing requirements;
- approval pathway.

## 3. Build the weird project on the same site

Keep the site constant.

Change the building system.

This isolates the building-platform variable.

## 4. Run both through the same transmission audit

Do not give the weird project special treatment.

## 5. Identify state reforms that affect each interface

For example:

```text
STATE FINANCE REFORM
       ↓
COUNTY FINANCING INTERFACE

STATE FEE REFORM
       ↓
COUNTY FEE INTERFACE

STATE STREAMLINING
       ↓
COUNTY REVIEW INTERFACE

STATE BUILDING-STANDARD REFORM
       ↓
BUILDING PLATFORM INTERFACE
```

## 6. Create a "remaining friction" list

After applying the new state reforms:

> **What is still preventing the project from moving?**

That becomes the County-level policy research agenda.

# 12. The Most Important New County Question

The County does not necessarily need another abstract housing plan from us.

It may need a **translation document**:

> **California changed X. What does Santa Cruz County need to change, implement, measure, or stop doing so that X actually becomes housing?**

That is the bridge between state legislation and local implementation.

# 14. What We Should Not Do

Do not assume:

- state reform automatically equals local implementation;
- planned units equal occupied units;
- affordable units equal stable housing;
- reduced review time automatically equals lower total cost;
- lower construction cost automatically equals greater housing production;
- modular construction automatically equals cheaper construction;
- factory construction automatically solves land or financing;
- a veto means the underlying concept is invalid;
- a signed law means the intended outcome has already occurred.

Each of those is a testable proposition.

# 17. Working Hypothesis

> **California's 2026 reforms create a new reference condition for Santa Cruz County. The immediate research opportunity is not to wait for the reforms to mature, but to establish a baseline now, map the reforms onto existing County housing programs, and run conventional and adaptable building pathways through the same transmission audit.**

The experiment then asks:

> **What changed?**

and:

> **What did not change?**

and finally:

> **Where is the remaining friction?**

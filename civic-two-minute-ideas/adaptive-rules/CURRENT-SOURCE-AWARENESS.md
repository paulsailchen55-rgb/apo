# Current Source Awareness

The system must treat rules, agendas, meeting instructions, and project documents as changeable.

## Required behavior

1. Search the relevant official website before time-sensitive use when live search is available.
2. Prefer the newest applicable document and record retrieval time.
3. Compare newly found material with saved source records.
4. Flag changed, missing, superseded, contradictory, or inaccessible documents.
5. Separate confirmed requirements from assumptions.
6. Do not claim exhaustive verification when only partial sources were checked.
7. Ask the user to confirm with the clerk, agency, or official source when a conflict could affect participation.

## Source record fields

- Jurisdiction and agency
- Meeting/body
- Document title
- URL
- Publication or revision date
- Retrieval date/time
- Relevant section/page
- Applicability
- Verification status
- Notes on changes or conflicts

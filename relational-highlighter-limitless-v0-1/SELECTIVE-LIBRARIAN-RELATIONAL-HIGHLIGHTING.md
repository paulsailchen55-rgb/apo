# Selective Librarian and Relational Highlighting

The Relational Highlighter project begins from the experience of a particular word, phrase, or idea becoming salient inside a much larger information field.

The Selective Librarian provides a possible external-data counterpart.

The information field remains intact.

A retrieval layer identifies candidate material.

A highlighting layer makes particular passages, records, or relationships salient.

The human decides whether the highlighted relationship is actually meaningful.

Possible chain:

FULL INFORMATION FIELD
→ USER QUESTION
→ CANDIDATE RECORDS
→ THREE / FOUR RELATED HIGHLIGHTS
→ CONTEXT
→ HUMAN CONFIRMATION
→ POSSIBLE NEW OBSERVATION

This should not be treated as automatic truth discovery.

A highlight is a candidate for attention.

The surrounding context and original source remain necessary.

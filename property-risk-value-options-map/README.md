# Property Risk, Value and Options Map

## Status
Neutral research framework for site-specific property questions.

## Purpose
Distinguish known information from reported concerns, interpretations, hypotheses and unresolved questions.

## Layers
Property identity; current use; relevant records; land-use status; project status; proposed elements; documented requirements; environmental and infrastructure questions; existing community assets; risks and uncertainties; options without ranking; evidence needed; responsible source; responses and disagreements.

## Evidence labels
Observation; reported concern; documented fact; interpretation; hypothesis; proposal; disputed claim; verified evidence; unknown.

## Use
Developed in connection with the 1214 Soquel Avenue discussion and intended to be reusable for other property/project research.

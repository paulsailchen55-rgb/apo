# Selective Librarian and the Durable Civic Record

The Unified Civic Input Platform proposes that contributions from web, text, phone, mail, and in-person assistance be preserved in one accessible record.

The Selective Librarian can provide a navigation layer over that archive.

RAW CIVIC INPUT
→ DURABLE RECORD
→ INDEX / IDENTIFIERS
→ USER QUESTION
→ RELEVANT COMMENTS / ATTACHMENTS / OFFICIAL RESPONSES
→ ORIGINAL RECORD

This should remain distinct from official synthesis.

Official reports answer what the institution is reporting at a particular time.

The archive preserves what people actually submitted.

The Selective Librarian helps a later human find relevant material in the archive without requiring that person to read the entire collection.

Safeguards should include source visibility, retrieval explanation, broader search, original-record access, provenance, and clear separation between retrieved evidence and generated interpretation.

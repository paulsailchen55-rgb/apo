# Selective Librarian Connection

The Daily Information System asks how a person can obtain useful views of a persistent information space without repeatedly copying and re-encoding the underlying information.

The Selective Librarian is a complementary navigation layer:

PERSISTENT INFORMATION
→ INDEX / ADDRESSABILITY
→ HUMAN QUESTION
→ SELECTED VIEW
→ SOURCE / CONTEXT

A summary, transcript, index, or highlighted passage should remain distinguishable from the original information.

The Selective Librarian therefore fits the project's principle:

> Preserve what exists. Derive what doesn't.

The system should derive a useful view without silently replacing the source.

# Selective Librarian Interface

The Civic Flow Chart project makes public procedures visible and understandable without inventing procedures.

The Selective Librarian adds an information-navigation layer:

PUBLIC PROCEDURE / RECORD
→ INDEX / IDENTIFIERS
→ USER QUESTION
→ RELEVANT STEP / DOCUMENT / RECORD
→ SOURCE
→ HUMAN REVIEW

This can help a person navigate large agendas, staff reports, appendices, code sections, application records, meeting records, and related public documents.

The interface should preserve authority, sequence, time, cost, friction, pause and back paths, closure points, source provenance, and uncertainty.

The librarian should highlight relevant material without flattening the underlying procedure.

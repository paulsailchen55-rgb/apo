# Property Risk, Value & Options Map — Evidence Framework

## Status

Supplement to the existing reusable research framework.

## Evidence labels

- Observation
- Reported concern
- Documented fact
- Interpretation
- Hypothesis
- Proposal
- Disputed claim
- Verified evidence
- Unknown

## Core map

For a property/project, separately map:
- identity
- ownership/current use where public records establish it
- land-use status
- project status
- proposed elements
- required approvals
- environmental/infrastructure questions
- existing community assets
- risks and uncertainties
- options without ranking
- evidence needed
- responsible source
- responses/disagreements

## Purpose

The framework is designed to support informed civic discussion without silently converting concerns into facts or turning alternatives into rankings.

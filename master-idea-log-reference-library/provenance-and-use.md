# Master Idea Log Archive — Provenance and Use

This folder is a reference layer created from the September 2026 conversation and the corrected Master Idea Log artifact.

The 54-item log is not a list of approved projects. Some entries are principles, some research questions, some proposals, some experiments, and some personal/philosophical reflections.

The four functional packets are derived working documents:
- 1214 Soquel: immediate site-specific questions and community proposals.
- Santa Cruz: city-level policy/procedure ideas.
- California: state-level research/proposal ideas.
- Development Research Lab: experimental ideas that should be tested before promotion to policy.

The Master Idea Log should be used as a memory aid and selective reference for conversations with people. It deliberately preserves ideas that may later be rejected, revised, split, or combined.

The corrected PDF is the user-facing archival artifact. The Markdown log is the searchable text reference.

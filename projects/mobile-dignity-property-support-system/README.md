# Mobile Dignity and Property Support System

## Status
Preliminary archive of possibility. Developed incrementally through seven short steps.

## Purpose
Create a practical, repairable mobility and property-support system for people experiencing homelessness or unstable housing, with emphasis on transporting and protecting belongings, maintaining autonomy, and connecting people with services.

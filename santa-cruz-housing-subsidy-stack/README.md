# Santa Cruz County Housing — Subsidy Stack & Housing Stability

**Status:** PROPOSED / RESEARCH IN PROGRESS
**Updated:** September 24, 2026

This project studies housing as a connected feasibility system rather than as a single inclusionary-percentage question.

Core stack:

LAND → ZONING → DENSITY → DEVELOPMENT STANDARDS → FEES/EXACTIONS → CONSTRUCTION → FINANCING → SUBSIDIES → AFFORDABILITY → MARKET REVENUE → ADMINISTRATION → STABILITY → FEASIBILITY

Latest finding:

> Affordability is not the same as housing stability.

A unit can satisfy an AMI or affordability definition at a point in time while the household, provider, or program remains vulnerable to administrative delay, income interruption, compliance requirements, landlord participation constraints, or long-run operating and financing pressures.

See stability-and-administrative-cost-addendum.md for the current research extension.

The 2026 Santa Cruz County KMA feasibility study provides a local basis for extending development-feasibility analysis toward long-run stability by modeling affordable rents, development costs, stabilized NOI, and inclusionary financial impacts.

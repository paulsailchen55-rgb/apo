# KINSHIP — Start Here

KINSHIP is a conceptual research and engineering project for a modular, amphibious, mobile, and interconnectable family-scale habitat.

If you are new to the project, read in this order:

1. README.md — project identity and core principles.
2. 00-phase-25-27-repository-architecture-verbatim.md — preserved discussion that established the expanded repository architecture.
3. 01-system-definition.md — current conceptual system definition.
4. 02-architecture.md — current architectural concepts.
5. KNOWN-LIMITATIONS.md — what KINSHIP does not yet establish.
6. OPEN-QUESTIONS.md — unresolved engineering questions.
7. ROADMAP.md — proposed development sequence.

KINSHIP is not currently a certified building, vessel, aircraft, autonomous robot, or guarantee of survival. Claims must be distinguished as KNOWN, CALCULATED, TESTED, PROPOSED, SPECULATIVE, or UNKNOWN.

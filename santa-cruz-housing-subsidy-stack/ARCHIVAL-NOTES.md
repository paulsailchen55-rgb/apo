# Archival Notes

## Why this archive exists

Some project material was drafted during the housing research workflow but was not reliably posted to GitHub. This folder preserves the work separately so the project does not depend on whether a particular GitHub write succeeded.

## Core conceptual history

1. Started with a **housing subsidy stack**: direct subsidies plus regulatory, infrastructure, financing, market, and administrative capacity.
2. Added **affordability vs. stability**: an affordable unit at one point in time is not automatically a durable housing outcome.
3. Added **administrative transaction cost** and provider/household participation friction.
4. Expanded into **feasibility**: the cumulative burden on a project can affect whether housing is actually produced.
5. Developed the **Outside the Stack / Weird Housing Lab** for models that change the underlying ownership, land, operating, or transaction structure rather than adding another subsidy.
6. Developed **Technical Difficulties / Friction / Distortion / Loss Audit** as a transmission analysis.

## Preservation rule

Do not silently replace an earlier hypothesis with a later conclusion. Preserve the evolution of the question.

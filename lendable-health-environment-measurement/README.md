# Lendable Health & Home Measurement Technology

Status: thought experiment / research program concept, not yet a validated project.

Purpose
-------
Explore whether existing public-library lending infrastructure can provide ordinary residents temporary access to simple, validated devices for home health and home-environment measurement.

The concept is intended for renters and homeowners, with particular attention to apartments and HUD-assisted housing. The desired loan period is approximately one month so residents can observe conditions over time.

Core model
----------
Library -> standardized, easy-to-use device -> borrower -> local measurement -> borrower-controlled record -> optional destination.

Potential destinations include a patient's healthcare record, an environmental record, voluntary research, or an authorized agency. The library should not automatically become the owner or interpreter of personal measurements.

Design principles
-----------------
- Preserve possibility before deciding what the system is.
- Prefer devices that explain their own operation and require little or no training.
- Prefer local/offline measurement where practical.
- Transmit only what is necessary.
- Separate borrower identity, device identity, measurement identity, health identity, and environmental/public identifiers.
- Preserve provenance and chain of custody without unnecessarily exposing the borrower.
- Make sharing explicit and granular rather than using one blanket permission.
- Treat anonymization as a technical/privacy problem, not merely deletion of a name.
- Do not turn measurements into diagnoses, code violations, causation claims, or legal conclusions.
- Start with a small library pilot before proposing national scale.

Relationship to existing apo work
----------------------------------
This is a distinct application of ideas already represented in Personal Agency Infrastructure and Functional Phone/minimal-dependency work. The neighborhood tool-shed model remains a separate alternative.

Unresolved questions
--------------------
Device validity; FDA status; California/local library authority; sanitation and liability; privacy law; security architecture; lost/stolen-device controls; OCHIN/MyChart integration; environmental-data governance; nonprofit/grant structure; and appropriate recipients of voluntarily shared data.

Provenance
---------
Developed in the September 17-18, 2026 conversation. The user explicitly described the current work as a mental exercise / thought experiment to test how far the idea can be taken before deciding what it should become.

# Hard Questions

These questions are intended to turn the concern into researchable problems.

## Epistemology

- What constitutes ground truth for an AI system?
- How should conflicting primary sources be handled?
- How can provenance survive copying and transformation?
- How should uncertainty propagate from source data into model outputs?
- How can researchers measure whether a dataset contains systematic manipulation?

## Security

- Which documented attack classes map to Alteration, Omission, Delay, and Substitution?
- Which attacks can cross multiple trust boundaries?
- Which attacks can use legitimate credentials?
- Which attacks can produce effects without persistent malicious code?
- Which attacks are difficult to distinguish from ordinary defects?

## Detection

- What telemetry is necessary to reconstruct an AI-mediated information pathway?
- Which evidence must come from an independent system?
- How can investigators detect missing information?
- How can timing manipulation be distinguished from ordinary congestion?
- How can substitution be detected when the substituted component is itself authentic?

## Human factors

- How much does AI-mediated framing affect human decisions?
- Does repeated exposure to the same information increase perceived credibility?
- Can omission be more influential than false information?
- How should human reviewers respond when an AI result conflicts with independent evidence?
- What interface designs make provenance understandable without overwhelming users?

## Systems research

- What happens when retrieval, memory, tools, agents, and communication systems are chained?
- Can individually safe components create unsafe emergent behavior?
- How should trust boundaries be represented in agent architectures?
- What is the minimum viable independent channel for consequential decisions?
- Can an AI pathway be formally tested for integrity?

## Falsification

- What observations would show that a suspected mechanism is actually ordinary model behavior?
- What observations would show that a suspected coordinated mechanism does not exist?
- What experimental controls are needed?
- How do we prevent confirmation bias from turning anomalies into evidence?

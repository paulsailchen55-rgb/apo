# Property Risk, Value & Options Map

Classification: reusable due-diligence framework.

Map site conditions, existing uses, proposed program, rules, application status, environmental and infrastructure questions, agency authority, economic considerations, alternatives, evidence, and unresolved issues.

Tag entries as observation, reported concern, documented fact, interpretation, hypothesis, proposal, disputed claim, or unknown.

The framework does not itself determine legality, approval, or preferred outcome.

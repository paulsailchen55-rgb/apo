# Cross-Platform Integration

Initial platforms of interest:
- ChatGPT
- Claude
- Gemini

Longer-term possibility: a shared protocol or specification for audio-source labeling and provenance, with platform-specific implementations.

Potential components:
- Source type: live, recorded, mixed, or unknown.
- Source confidence.
- User-provided declaration.
- Evidence category.
- Timestamp and recording provenance.
- Privacy controls.

Platform capabilities and extension mechanisms must be verified separately before implementation claims are made.
